Task 3: Interactive Dashboard KPIs and Charts.
📌 Objective  
Build a professional interactive dashboard to visualize loan portfolio performance and communicate key insights clearly.

🧰 Tools Used

Power BI / Tableau

Cleaned dataset from Task 1 & Task 2

📊 Dashboard Components

KPIs (Cards):

Total Loan Applications

Total Funded Amount

Total Amount Received

Average Interest Rate (%)

Average Debt-to-Income (DTI) Ratio (%)

Good Loan % vs Bad Loan %
Charts & Visuals:

Loan Status Distribution (Donut Chart)

Funded vs Received Amount by Loan Status (Stacked Bar Chart)

Loan Applications by Status (Column Chart)

Average Interest Rate by Loan Status (Bar Chart)

Average DTI Ratio by Loan Status (Bar Chart)

Loan Amount Distribution by Loan Status (Boxplot/Column Chart)

Loan Purpose by Sub-Grade (Horizontal Bar Chart)

Loan Applications by State (Map)

Loan Applications by Employment Length (Bar Chart)

Filters (Slicers):

Purpose

Grade

State

Employment Length

Verification Status
