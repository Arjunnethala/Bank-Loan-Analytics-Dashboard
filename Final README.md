# 🏦 Bank Loan Analytics Dashboard

## 📌 Project Overview

The **Bank Loan Analytics Dashboard** is a Power BI data analytics project developed to analyze loan portfolio performance, repayment behavior, loan quality, and key financial indicators.

The project transforms raw bank loan data into meaningful business insights through data cleaning, exploratory analysis, and interactive dashboard visualization.

--- 

## 🎯 Project Objective

The main objective of this project is to:

- Analyze overall loan portfolio performance.
- Monitor loan applications and funded amounts.
- Compare good loans and bad loans.
- Understand loan repayment behavior.
- Analyze interest rates and Debt-to-Income (DTI) ratios.
- Identify patterns across different loan purposes and loan statuses.
- Provide an interactive dashboard for data-driven decision-making.

---

## 🛠️ Tools & Technologies

## 🔍 Data Analysis Performed

The project includes:

### 1. Data Cleaning & Preparation
- Handled missing and null values.
- Checked duplicate records.
- Corrected data types.
- Standardized inconsistent values.
- Removed unnecessary data.
- Prepared the dataset for analysis.

### 2. Exploratory Data Analysis
- Analyzed loan application trends.
- Examined loan status distribution.
- Analyzed loan purposes and loan grades.
- Compared interest rates.
- Analyzed DTI ratios.
- Compared funded amounts with amounts received.
- Identified important business patterns and insights.

### 3. Interactive Dashboard
- Developed an interactive Power BI dashboard.
- Added KPI cards.
- Created Good vs. Bad Loan analysis.
- Added loan status analysis.
- Added interactive loan-purpose filtering.
- Designed visuals for quick business performance monitoring.
