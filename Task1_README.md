# SWYNEX – Bank Loan Analytics
## Task 1: Data Cleaning & Preparation

### 📌 Project Overview

This task focuses on cleaning and preparing a raw Bank Loan dataset for further analysis.

The objective was to identify data quality issues, clean the dataset, standardize the data, and prepare an analysis-ready dataset.

### 🛠️ Tools Used

- Microsoft Excel
- Power Query
- Power BI

### 🔍 Data Cleaning Activities

The following data preparation steps were performed:

- Identified and handled missing/null values.
- Checked and removed duplicate records.
- Corrected incorrect data types.
- Standardized inconsistent values and formats.
- Removed unnecessary data where required.
- Checked numerical and categorical fields for consistency.
- Validated the cleaned dataset before analysis.

### 📊 Dataset

The dataset contains bank loan information such as:

- Loan Amount
- Funded Amount
- Amount Received
- Interest Rate
- Debt-to-Income Ratio (DTI)
- Loan Status
- Loan Purpose
- Loan Grade
- Employment Length
- Home Ownership
- Annual Income
- Verification Status

###  Objective

The main objective of this task was to transform the raw dataset into a clean, consistent, and analysis-ready dataset that can be used for Exploratory Data Analysis and dashboard development.

### Outcome

The Bank Loan dataset was successfully cleaned and prepared for the next stage of the project: **Exploratory Data Analysis (EDA).**
