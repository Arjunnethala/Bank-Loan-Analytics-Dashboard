Task 2: Exploratory Data Analysis (EDA)
📌 Objective  
Using the cleaned dataset from Task 1, this task focuses on exploring the data to uncover trends, correlations, and patterns that provide business insights.

🧰 Tools Used

Python (Pandas, NumPy)

Seaborn & Matplotlib for visualization

Jupyter Notebook

📊 Key Analysis Steps

Checked dataset structure and data types

Verified missing values (none found)

Generated correlation heatmap for numeric variables

Compared Loan Status against Income, Loan Amount, and Grade

Analyzed trends across States and Employment Length

📈 Visualizations

Correlation Heatmap (numeric features)

Boxplots of Loan Status vs Income & Loan Amount

Countplots of Loan Status vs Grade, State, Employment Length

💡 Insights

Income vs Loan Status: Borrowers with lower annual income show higher default rates.

Loan Amount vs Loan Status: Larger loan amounts are more likely to default compared to smaller loans.

Grade vs Loan Status: Lower grades (D, E, F) have significantly higher default rates than higher grades (A, B).

State Trends: Certain states show higher concentrations of defaults, indicating regional risk factors.

Employment Length: Shorter employment history correlates with higher default probability.
